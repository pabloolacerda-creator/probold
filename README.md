# Probold Marketing Digital — Site

Site institucional de uma página (landing page) da Probold Marketing Digital.

## O que é
Página única e responsiva com: abertura, quem somos, serviços, propósito, parceiros e contato por WhatsApp.

- `index.html` — a página
- `styles.css` — os estilos
- `assets/` — logo, foto e imagens dos serviços

## Como ver no computador
Abra o `index.html` no navegador, ou rode um servidor local:

```bash
python -m http.server 8777
```
Depois acesse http://127.0.0.1:8777
